Manifesto

AI made software faster than understanding.

Technical debt is code that costs more later. Cognitive debt is sharper: code that exists, passes tests and maybe ships, but cannot be explained, modified or defended by the people responsible for it.

Sibi is not an AI coding assistant. It is an ownership engine for AI-generated software.

Ownership states are cognitive, not technical.

  1. ownedPrompt Generation
  2. partialEvidence Collection: weak tests
  3. gapRuntime Validation: confuses evaluation with validation
  4. recoveredDeletion-risk argument added after retry
