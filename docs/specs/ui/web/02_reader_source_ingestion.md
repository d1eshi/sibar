# Web UI Spec 02: Reader Source Ingestion

## Goal

Make source ingestion the first product moment in the web reader, then get out
of the way once reading begins.

## First Open

The empty reader should show:

1. `Sibi Reader` label
2. centered source input
3. `Cargar` and `Demo`
4. short line explaining the action
5. static source-type examples
6. hint of the future reading surface

## Reading

After source load:

1. source identity is quiet
2. article content is primary
3. text selection offers one direct save action
4. no category selector is required
5. no persistent side panels appear by default

## Saved

After saving:

1. saved text is subtly marked
2. confirmation is small
3. saved count can appear collapsed
4. reading flow remains primary

## Non-Goals

1. No personalized recommendations.
2. No source marketplace.
3. No search engine.
4. No AI summary as first-screen concept.
5. No note-management dashboard.

## Acceptance

1. First-open makes the paste action obvious.
2. Source examples are generic and non-personalized.
3. Loaded state removes onboarding suggestions.
4. Save flow has one primary action.
5. The reader stays usable on desktop and mobile.
