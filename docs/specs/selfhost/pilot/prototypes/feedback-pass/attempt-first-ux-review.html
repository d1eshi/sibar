Attempt-First UX Note (from public-demo validator): The current demo shows a default finding (the "grounded" answer) immediately upon page load, before the reviewer has selected any answer state. The question for this review is: Is seeing the default finding immediately acceptable, or should findings stay hidden until the reviewer explicitly selects an answer state? Seeing the finding first may influence how a reviewer thinks about the question; hiding it preserves strict attempt-first ordering but requires one more click.
