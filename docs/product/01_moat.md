# Moat

## Category

The strongest category is not "understand this repo".

The stronger category is:

> Codebase learning infrastructure for AI-generated and unfamiliar software.

More aggressive:

> Sibi is the comprehension layer for AI-generated software.

## Why This Is Defensible

Cursor, Copilot, Claude Code, and similar agents optimize for output:

1. generate code
2. modify files
3. explain on demand
4. prepare changes
5. reduce friction

Sibi optimizes for a different state:

1. attempt first
2. explain in your own words
3. detect misconceptions
4. repair concepts
5. verify retention
6. decide readiness

That incentive difference matters. Sibi becomes better when it knows when not to answer immediately.

## Proprietary State

The moat is not a repo graph alone. The moat is the accumulated understanding graph.

Sibi should accumulate:

1. Artifact Graph: what exists in the generated or imported system
2. Concept Graph: which technical concepts the artifact expresses
3. Learner Graph: what the user can explain, connect, apply, and teach
4. Misconception Graph: recurring confusions such as reward vs loss, adapter vs service, runtime vs request lifecycle
5. Practice Graph: which questions, hints, repairs, and challenges improve understanding
6. Memory Graph: what was retained, forgotten, or transferred to new artifacts
7. Team Graph later: how a team repeatedly misunderstands or teaches its own systems

Chat history is cheap. Understanding memory is the asset.

## Initial Wedge

Own the first 10 hours inside an unfamiliar or AI-generated codebase.

The first user story:

```text
I asked an agent to build something useful.
Now I need to reverse engineer it until I can change it without pretending.
```

The product is working when the user can:

1. explain the architecture
2. identify the core concepts
3. modify a bounded part
4. predict what could break
5. remember the flow after delay
6. transfer the concept to a second artifact

## Pitch

Short version:

> Sibi turns generated software into durable technical understanding.

Company version:

> Sibi is the system of record for engineering understanding.
