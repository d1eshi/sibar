# Product Foundation

## Thesis

Sibi is not an AI coding assistant.
Sibi is not a repo chat.
Sibi is not a generic tutor.

Sibi is a Build-to-Learn system:

> It takes a real software artifact, guides the learner through reverse engineering, detects conceptual gaps, and builds durable understanding memory.

The problem Sibi owns is not "can AI write code?".
The problem is:

> After AI or agents create software, can the human explain, modify, debug, and extend it as their own?

## First User

The first user is the builder using AI agents heavily.

The user asks agents to create or modify real systems, then needs to recover ownership:

1. What did the agent build?
2. Which concepts does this artifact contain?
3. What do I think I understand?
4. Where is my model wrong or shallow?
5. What should I practice before trusting myself to change it?

## Core Product Loop

```text
artifact exists
  -> Sibi identifies concepts and flows
  -> user predicts/explains before receiving answers
  -> Sibi detects gaps and misconceptions
  -> user repairs through hints, questions, and challenges
  -> Sibi records evidence of understanding
  -> Sibi produces readiness guidance
```

This loop is stricter than reading and slower than autocomplete on purpose.

## Product Promise

Sibi should eventually be able to say:

> You are ready to change this part of the system.

or:

> You are not ready yet. You are confusing the runtime boundary with the persistence boundary. Repair that first.

That is the difference between assistance and ownership verification.

## Product Non-Goals For v0.1

v0.1 does not need:

1. a macOS ambient observer
2. voice capture
3. screen capture
4. Vim or editor plugins
5. team dashboards
6. automatic workspace mutation
7. agent orchestration
8. a full generated-project builder

The user may bring a repo generated by an agent. Sibi v0.1 does not need to generate the repo itself.

## North Star

Sibi exists to preserve human ownership in AI-assisted engineering.

The v0.1 wedge is one reproducible Build-to-Learn session over one real artifact.
