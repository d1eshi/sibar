The Moat

Why SIBI Is Not Repo Chat

Generic repo chat tools optimize for output: generate code, modify files, explain on demand. They reduce friction between you and the answer.

SIBI optimizes for a different state: understanding ownership. It asks you to attempt an answer first, then compares your reasoning to concrete repository evidence. When you miss something, it diagnoses the gap and gives you a specific repair — not a generic explanation.

SIBI vs. chat: Chat tells you what the code does. SIBI tells you whether you can own a bounded part of the system and what to repair before you touch it.

This demo walks through one simulated self-hosted codebase slice. It uses fixture data only — no backend, no live repo, no model calls. Every answer state is traced to a concrete evaluator and benchmark report case.

Artifact Boundary

What SIBI can evaluate in this demo

In Scope

  • src/ — runtime, evals, scripts
  • Tests/ — test suite
  • sibar.selfhost.manifest.json
  • package.json, tsconfig.json
  • pnpm-lock.yaml
  • docs/specs/selfhost/pilot/ — gold cases, mastery checks

Out of Scope

  • docs/product/ — product docs (not evaluated)
  • docs/missions/ — mission artifacts
  • agent-chat-*.md — planning notes
  • node_modules/ — dependencies
  • dist/, .build/, .swiftpm/ — build artifacts
  • Any file not in the manifest included_paths

Evidence boundaries matter: a claim must cite repo paths inside the artifact boundary. Evidence from outside the boundary cannot support a readiness finding. This prevents overclaiming from partial knowledge.

What This Demo Is — and Is Not

This demo is:

  • Backed by fixture data traced to evaluator/benchmark reports
  • Self-contained static HTML with no backend, database, or auth
  • A prototype showing the Build-to-Learn loop for one concept
  • Deployable as a static site to Vercel, Netlify, or GitHub Pages

This demo does not claim:

  • That SIBI can analyze any arbitrary repository
  • That SIBI understands the whole codebase from one answer
  • That a single correct answer means durable ownership
  • That this demo represents the full product or SwiftUI surface
  • That SIBI is proven superior to any competitor beyond the implemented evidence
