# 005 - Self-Hosted Dataset Location (Superseded Decision Brief)

## Current Decision (in force)

The accepted location for self-hosted MVP pilot artifacts is:

```text
docs/specs/selfhost/pilot/
```

This decision is active for the current execution layer. Older mission-oriented
paths are historical and are no longer allowed for current self-hosted MVP
artifact storage.

## Historical Option Set (for traceability; no longer active)

This decision originally compared two options:

- **Option A**: `docs/specs/selfhost/dataset/` (or related selfhost-specific path)
  was considered and abandoned in favor of the pilot location above.
- **Option B**: `docs/missions/sibi-v01-build-to-learn/evals/dataset/`
  was explicitly rejected for current routing because self-hosted MVP artifacts
  must live with `docs/specs/selfhost/*`.
